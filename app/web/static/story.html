CADEIncident response, step by step

Connect to CADE

Enter a CADE API key once before the demo. It stays in this browser tab only. An analyst key also lets you confirm the findings when a run has finished.

Confirm the findings

Do this after checking what the run found. CADE accepts it once per run and it cannot be undone.

Only with both ticked is the playbook saved to the library, so a similar alert can reuse it. The router is also rewarded for its decision, more when the findings are kept.
